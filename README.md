Task Logger – ReactApp3

A full‑stack task management application built with **Next.js 15 (App Router), TypeScript, Tailwind CSS, and a real SQLite database. This project demonstrates server‑side data fetching, client‑side data fetching, API mutations (POST, PATCH, DELETE), and form handling – as required by Chapters 7–9 of Learn React with TypeScript. 


 📋 Features

 ✅ View a list of all tasks (fetched from a real SQLite database)
 ➕ Add a new task using a controlled React form
 🔄 Mark a task as complete/incomplete (PATCH mutation)
 🗑️ Delete a task (DELETE mutation)
 📊 Server‑side data fetching – task statistics rendered on the server
 🌐 Client‑side data fetching – tasks loaded via `/api/tasks`
 💾 Persistent storage – tasks survive server restarts (SQLite)
